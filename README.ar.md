# نَسْج — NASJ

**أداة مفتوحة المصدر بلغة Rust لرسم خريطة لمسارات Nginx والبنية التحتية.**

> المشروع في مرحلة التأسيس. تحليل Nginx وتصدير HTML/SVG غير متاحين بعد.

- **v0.1:** تحليل إعدادات Nginx وتصدير JSON وDOT وSVG وتقرير HTML تفاعلي يعمل بدون إنترنت.
- **v0.2:** اكتشاف اختياري لحاويات Docker وخدمات systemd والعمليات المحلية.
- **v0.3:** خادم ويب محلي اختياري.

تقدر حاليًا تجربة بيانات افتراضية:

```sh
cargo run -p nasj-cli -- demo --format json
```

البرنامج مصمم للقراءة فقط، بدون تعديل إعدادات Nginx أو رفع بياناتك لخدمات خارجية.
