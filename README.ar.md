# نسج — NASJ

**انسج بنيتك التحتية في صورة واضحة.**

نسج أداة مفتوحة المصدر بلغة Rust تعمل من سطر الأوامر. تقرأ إعدادات Nginx
وملفات `include` المعلنة، ثم تحولها إلى خريطة ذات مراجع للملف ورقم السطر.
تدعم هذه النسخة تصدير JSON وDOT وSVG وتقرير HTML تفاعلي في ملف واحد يعمل
دون إنترنت أو خادم ويب.

> **نسخة تطوير غير منشورة.** التنفيذ موجود في فروع المراجعة وطلبات الدمج
> [#1](https://github.com/marawan6569/Nasj/pull/1) و
> [#8](https://github.com/marawan6569/Nasj/pull/8) و
> [#9](https://github.com/marawan6569/Nasj/pull/9) و
> [#10](https://github.com/marawan6569/Nasj/pull/10).
> قد لا يحتوي الفرع الافتراضي على هذه التغييرات بعد. لا تتوفر حزمة إصدار منشورة.

## التثبيت والتجربة

ثبت Rust المستقر وأداة الربط الخاصة بنظامك. من نسخة المستودع التي تحتوي
على التنفيذ، نفذ:

```sh
cargo install --locked --path crates/nasj-cli
nasj --help
```

لتجربة فرع التنفيذ قبل دمجه:

```sh
git clone --branch feat/offline-reports https://github.com/marawan6569/Nasj.git
cd Nasj
cargo install --locked --path crates/nasj-cli
```

تأكد من وجود مجلد أدوات Cargo في `PATH`. لا يحتاج التشغيل إلى Graphviz أو
Python أو Node.js أو صلاحيات الجذر. تم التحقق باستخدام Rust 1.99.1، ولم يحدد
حد أدنى أقدم مدعوم بعد.

## الاستخدام

```sh
nasj map --config ./nginx.conf --format json
nasj map --config ./nginx.conf --format dot -o topology.dot
nasj map --config ./nginx.conf --format svg -o topology.svg
nasj map --config ./nginx.conf --format html -o report.html
```

افتح `report.html` مباشرة في المتصفح. يحتوي على جميع الموارد محليا، ويدعم
التكبير والتحريك والبحث والتصفية واختيار العقد وفحص مصادرها والأدلة المرتبطة
بالعلاقات، مع مظهر فاتح وآخر داكن وتخطيط للشاشات الصغيرة.

استخدم أسماء إخراج جديدة؛ ترفض الأداة الكتابة فوق أي ملف أو رابط رمزي موجود.
يذهب الإخراج إلى المخرج القياسي عند غياب `-o`. الأمر `demo` ينتج بيانات
افتراضية فقط، ولا يحلل إعدادات حقيقية:

```sh
nasj demo --format html -o demo.html
```

تحل مسارات `include` النسبية انطلاقا من مجلد ملف الإعداد الرئيسي، حتى داخل
الملفات المضمنة. ترتب مطابقات الأنماط وتكشف الدورات، وتقيد القراءة بهذا
المجلد بعد حل الروابط الرمزية. يمكن تحديد مجلد أساس أو السماح صراحة بمسارات
مضمنة خارجه:

```sh
nasj map --config ./nginx.conf --prefix ./config --format json
nasj map --config ./nginx.conf --allow-external-includes --format json
nasj map --config ./nginx.conf --strict --format json
```

يمنع `--strict` إنشاء التقرير عند وجود أي تحذير. تؤدي أخطاء الصياغة والقراءة
والتضمين إلى الفشل دون خريطة جزئية. تظهر التحذيرات في جميع الصيغ وفي لوحة
التشخيص داخل تقرير HTML.

## النطاق والحدود

تغطي النسخة مستمعات HTTP وTLS وعناوين IPv4 وIPv6 ومقابس Unix وأسماء المضيفين
وكتل الخادم والمسارات العادية والدقيقة والتعبيرات النمطية والمتداخلة، إضافة
إلى وجهات HTTP(S) ومجموعات upstream وأعضائها والتحويلات وجذور الملفات وalias.
تحتفظ الخريطة بمصدر الإعداد ورقم السطر.

العلاقات تصف **الإعدادات المعلنة** ولا تؤكد أن الخدمة تعمل فعليا. تبقى الوجهات
المتغيرة والمسارات الشرطية وسياقات إعادة الكتابة غير المدعومة غير محسومة،
ولا تختلق الأداة روابط إلى وجهات مفترضة. لا تحاكي اختيار المسار لطلب حقيقي،
ولا تستبدل فحص `nginx -t`. راجع [عقد التحليل](docs/ANALYSIS.md) للحدود الدقيقة.

لا تعدل الأداة Nginx ولا تعيد تحميله، ولا ترفع الصلاحيات أو تتصل بمقبس Docker
أو ترسل بياناتك إلى خدمة خارجية. تحذف محتوى الاستجابات والرؤوس غير اللازمة،
وتحجب بيانات اعتماد الروابط والاستعلامات والأجزاء السرية وتؤمن ترميز المخرجات.
تبقى أسماء البنية التحتية ومسارات الملفات ظاهرة؛ راجع التقرير قبل مشاركته،
فلا يوجد ضمان لاكتشاف كل الأسرار الممكنة.

المصححة غير متاحة، لذلك يبقى نشر الهوية البصرية معلقا.
