# NASJ logo assets

NASJ is written **نسج** in Arabic (not **تسج**). The initial Arabic letter **ن** has exactly one dot above.

The corrected PNG variants will be committed in a separate branding PR so assets can be visually verified before publication.

Suggested names: `logo_primary_transparent.png`, `logo_icon_only_transparent.png`, `logo_app_icon_color.png`.
