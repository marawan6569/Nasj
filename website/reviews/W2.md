the embedded SVG must equal its companion export. Two differently named roots

The initial browser test assumed Escape preserved a native search field; Chromium
also clears that field. The corrected test restores the query before testing
graph-node keyboard selection. No viewer change or weakened assertion was used.
An initial parallel generator-cache write exposed `ETXTBSY`; cache installation
now uses atomic replacement, leaving concurrently executing verified bytes intact.

W0's Precision Topology conventions, bundled fonts, branding, approved larger
export cards and desktop framing remain unchanged. The available W0 artifact
bundle contains homepage/adaptation references; a separate approved demo-page
composition was not available locally. W2 uses the established shell/tokens and
native disclosures without inventing a new visual direction. The new demo-page
composition still needs independent visual review.

The viewer is not patched for accessibility or mobile behavior. Automated wrapper
axe coverage explicitly excludes the iframe; functional viewer checks do not
constitute full viewer WCAG certification. Firefox/WebKit, physical iOS/Android,
assistive technology, manual touch/zoom and comprehensive W4 performance gates
remain unperformed. Timing observations are local lab data, not field INP.
Visual inspection of the new captures confirms readable wrapper text and source
labels at 320/390px. The released viewer deliberately zooms into selected nodes;
context can remain outside the graph frame. On mobile, its inspector can be below
the visible iframe region and requires internal scrolling. The original viewer
provides Fit view/Readable scale controls; the wrapper also offers standalone
viewing and complete text evidence. These observations are not physical touch
validation. Three sequential unthrottled desktop search/selection measurements
were 34.5, 34.1 and 34.1 ms; they are not a mobile launch-performance gate.

Potential inherited viewer limitations require explicit disposition before launch;
this handoff is not a blanket waiver.

The generator is intentionally Linux x86_64-only, matching the approved published
executable. Other machines can inspect/build the pinned artifacts; regeneration
requires that environment. Secret-pattern scanning is supplementary and does not
guarantee that arbitrary secrets are absent. No hosted W2 CI, deployment, or live
Pages verification has occurred; those require later authorization.
